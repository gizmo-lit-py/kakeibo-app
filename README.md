# 家計簿アプリ（Flask）

Flask / SQLite を使って作成したシンプルな家計簿アプリ。  
ユーザー登録・ログイン後に、収入・支出の管理（追加 / 一覧 / 編集 / 削除）ができる。

---

## 主な機能

- ユーザー登録 / ログイン / ログアウト
- 取引の追加（収入・支出）
- 取引一覧の表示
- 取引の編集
- 取引の削除
- 収入合計 / 支出合計 / 残高の計算
- ログインユーザーごとのデータ管理

---

## 使用技術

- Python
- Flask
- Flask-SQLAlchemy
- Flask-Login
- SQLite
